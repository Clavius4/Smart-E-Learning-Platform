# 🎓 Smart E-Learning Platform

Complete e-learning platform with backend API, admin dashboard, and instructor portal.

## 🏗️ Architecture

- **Backend**: Node.js + Express + MongoDB
- **Admin Dashboard**: React + TypeScript + Vite
- **Instructor Portal**: React + JavaScript + Vite
- **Containerized**: Docker + Docker Compose

## 🚀 Quick Start

```bash
git clone https://github.com/suleiman309/smart-learning-platform-docker.git
cd smart-learning-platform-docker
docker-compose up --build
```

## 🌐 Access

- **Backend API**: http://localhost:5000
- **Admin Dashboard**: http://localhost:3000  
- **Instructor Portal**: http://localhost:5173
